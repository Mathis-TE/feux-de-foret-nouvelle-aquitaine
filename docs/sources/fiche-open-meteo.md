# Fiche source — Open-Meteo Historical Weather API (ERA5)

**Auteur :** Amine ASBANE · **Documentation consultée le 18/11/2026 :** open-meteo.com/en/docs/historical-weather-api, page d'accueil open-meteo.com, README GitHub `open-meteo/open-meteo`.
**Fichier ouvert :** `open-meteo-44_82N0_56W22m.csv`, téléchargé depuis `archive-api.open-meteo.com/v1/archive` pour un point de Bordeaux (modèle par défaut, 8 variables quotidiennes, 2006-2025). Les fichiers `data/meteo_quotidienne/<dep>.csv` du groupe n'ont pas été ouverts.

| Rubrique | Valeur |
|---|---|
| Propriétaire et système | Open-Meteo (Patrick Zippenfenig), code source sous licence AGPLv3. Données de réanalyse ERA5 et ERA5-Land d'ECMWF / Copernicus. Point d'accès : `archive-api.open-meteo.com/v1/archive`. |
| Mode d'accès et format | API HTTP GET, sans clé pour un usage non commercial. JSON par défaut, CSV et XLSX disponibles (`format=csv`). Paramètres : `latitude`, `longitude`, `start_date`, `end_date`, `daily`, `timezone` (obligatoire pour les variables quotidiennes), `models`. Pas de téléchargement de fichier brut. |
| Grain (une ligne = ?) | Un jour pour un point. Vérifié dans le fichier : une ligne par date (`time`, 7 305 dates distinctes). Le point renvoyé est la cellule de grille la plus proche : demandé `44.84 / -0.58`, renvoyé `44.815464 / -0.5563965`, altitude 22 m, fuseau Europe/Paris. |
| Emprise géographique | Mondiale (grille). Le choix des 12 départements vient du groupe, pas de la source. |
| Période réellement couverte par les données | Fichier ouvert : du 2006-01-01 au 2025-12-31, soit 7 305 jours (20 ans dont 5 années bissextiles), sans trou ni doublon de date et sans valeur manquante. Documentation : ERA5 depuis 1940, ERA5-Land depuis 1950, IFS depuis 2017. Le fichier a été demandé **sans paramètre `models`** (modèle par défaut `best match`) : la documentation précise que ce modèle combine IFS, ERA5 et ERA5-Land et conseille ERA5 ou ERA5-Land seul pour étudier le changement climatique sur plusieurs décennies. Le modèle utilisé par les fichiers du groupe : **non vérifiée** (fichiers non ouverts). |
| Date de dernière mise à jour affichée sur la fiche | Aucune date de mise à jour de jeu de données n'est affichée sur la page consultée (pied de page : 2022-2026). Les jeux ERA5 sont mis à jour chaque jour avec 5 jours de retard. |
| Fréquence de mise à jour | ERA5 et ERA5-Land : quotidienne, avec 5 jours de délai (tableau « Data Sets » de la documentation). |
| Volumétrie | Fichier ouvert : 7 309 lignes au total, soit 4 lignes de métadonnées et d'en-tête puis 7 305 lignes de données, 9 colonnes (`time` + 8 variables), 362 423 octets (environ 354 Ko) pour un point. Pour les 12 départements du groupe : 12 × 7 305 = 87 660 lignes attendues (calcul, fichiers du groupe non ouverts). |
| Clés disponibles | `time` (date au format AAAA-MM-JJ) est la seule clé. Le fichier ne contient ni code département ni code commune : les 4 premières lignes donnent latitude, longitude, altitude, décalage UTC et fuseau du point. La jointure avec les feux se fait donc sur la date, après avoir rattaché chaque point à un département (choix du groupe : un point par département). |
| Données personnelles | Aucune dans les données (grandeurs météorologiques, coordonnées de grille). Page « Terms & Privacy » d'Open-Meteo : le site ne collecte aucune donnée personnelle ; l'API gratuite ne collecte que des informations non personnelles ; l'adresse e-mail et l'IP ne sont collectées que pour la lettre d'information. |
| Licence | Données sous CC BY 4.0. API gratuite pour un usage non commercial (moins de 10 000 appels par jour) ; usage commercial sur abonnement. Attribution obligatoire : afficher « Weather data by Open-Meteo.com » avec un lien partout où les données sont montrées. |
| Variables disponibles (daily) | Fichier ouvert, colonnes avec leurs unités : `temperature_2m_max (°C)`, `temperature_2m_mean (°C)`, `precipitation_sum (mm)`, `wind_speed_10m_max (km/h)`, `wind_gusts_10m_max (km/h)`, `relative_humidity_2m_min (%)`, `et0_fao_evapotranspiration (mm)`, `soil_moisture_0_to_7cm_mean (m³/m³)`. Plages observées : température maximale de −2,4 à 41,7 °C ; précipitations de 0 à 51,4 mm ; rafales de 9,7 à 119,5 km/h ; humidité relative minimale de 17 à 96 %. **Piège :** les noms de colonnes contiennent l'unité entre parenthèses et il y a 3 lignes avant l'en-tête (`skiprows=3` pour lire le fichier avec pandas). |
| Questions de mon analyse | Q1 : températures, précipitations et humidité du sol sur 2006-2025 pour suivre le climat. Q3 : variables explicatives du modèle de prédiction. |
